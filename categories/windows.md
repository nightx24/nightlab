# 💻 Windows

## 🧹 Debloat & Windows Tweaking

- [Win11Debloat](https://github.com/raphire/win11debloat) — PowerShell-based Windows 11 debloat and customization tool
- [Chris Titus Tech WinUtil](https://github.com/ChrisTitusTech/winutil) — Windows utility for installing apps, tweaking settings, debloating and system maintenance

## 🧰 Open Source

- [WinGet](https://github.com/microsoft/winget-cli) — Windows package manager
- [Everything](https://www.voidtools.com/) — fast file search
- [7-Zip](https://www.7-zip.org/) — file archiver
- [VLC](https://www.videolan.org/vlc/) — multimedia player

> ⚠️ Debloat and system-tweaking tools can remove apps or change Windows settings. Review the available options before applying changes, and keep a restore point/backup when possible.
