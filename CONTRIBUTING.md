# 🤝 Contributing to NightLab

1. Add resources that are useful, free, open-source, privacy-friendly, or legally accessible.
2. Prefer official project links.
3. Include a short description.
4. Do not submit malware, scams, piracy hosts, or links to unauthorized copyrighted copies.
5. Check links before opening a pull request.

For larger collections, add the original source/index rather than copying its entire contents.
